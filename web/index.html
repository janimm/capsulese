Hello Capsule fans!

Time just flies by... It has been 10 years since first release of Capsule game!
This is a 10th Anniversary Special Edition of Capsule game. Some of the New features:

  • New TIME CHALLENGE game mode. Huge fun for experienced Capsule players.
  • New, full color graphics.
  • New sound effects.
  • 7 in-game languages, English, Finnish, Svedish, German, French, Spanish, and Italy.
  • Completely re-written code, works also with latest computers.
  • Installation package for easy installation and removal.

Some features retained from original version:

  • Challenging single player game with 25 levels.
  • Split screen 2 player mode.
  • 'Light Touch'™ controls for fast and precise gameplay.
  • Gamepad / Joystick support

 

System Requirements:

  • Windows 98,2000,XP,Vista
  • 2.2Mb Free hard disk space
